# PROJETA - Sistema de Gestão Estratégica de Projetos IPMA-D

Sistema corporativo de gestão de projetos baseado no referencial de competências **IPMA ICB4 (Nível D)** e estruturado sobre o template documental homologado de 16 artefatos gerenciais.

---

## 🌐 Acesso em Produção (Live na Nuvem)

O sistema está implantado e disponível online em:
👉 **[https://u-trace-fawn.vercel.app/projeta](https://u-trace-fawn.vercel.app/projeta)**

---

## ☁️ Arquitetura em Nuvem

- **Hospedagem & CDN**: Vercel (Edge Network global de alta velocidade)
- **Banco de Dados & Storage**: Supabase (`https://fvsrnuovfzcugkwdwixs.supabase.co`)
- **Exportação Excel**: OpenXML / ExcelJS em memória no navegador (100% fiel ao template `.xlsx` oficial)
- **Exportação PDF**: Renderizador CSS Paged Media A4 executivo nativo
- **Ciclo de Vida do GP**: Wizard UX em 3 passos + Gestão pelas 4 fases (Iniciação, Planejamento, Execução Contínua e Encerramento)
